# OptiC — Gestão Inteligente para Óticas 👓🚀

O **OptiC** é um Web App inovador desenvolvido para simplificar o dia a dia de vendas em óticas. Ele transforma tabelas complexas de lentes em uma plataforma de consulta ágil. Ideal para ser utilizado em computadores ou tablets diretamente no balcão de atendimento.

---

## ✨ Principais Funcionalidades

- **Consulta Inteligente de Lentes:** Busca rápida e categorizada por tipo de lente (Simples, Surfaçada, Ocupacionais e Progressivas) e fabricantes (Kodak e Essilor).
- **Busca Tolerante a Falhas:** Sistema adaptado para ignorar erros de digitação de categorias em bases de dados (singular/plural) e suporte total a acentuações.
- **Visualizador de Detalhes (Modal):** Clique rápido na lente para abrir informações detalhadas do produto e valores de forma isolada.
- **Arquitetura Nuvem/SaaS:** Conexão direta via API de alta velocidade com o banco de dados na nuvem (Supabase).

---

## 🛠️ Tecnologias Utilizadas

- **Front-end:** HTML5, CSS3 (Layout Responsivo e Grid System adaptado para desktop).
- **Tipografia e Ícones:** Google Fonts (Barlow) & Tabler Icons.
- **Banco de Dados (Backend as a Service):** [Supabase](https://supabase.com/) (PostgreSQL).
- **Deploy Recomendado:** Netlify.
